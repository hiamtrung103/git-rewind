BRING YOUR OWN HISTORY
Every repo has a story.
Export your committed history with the included CLI, then open the JSON here. Your file stays in this browser.
  1. 01
    Export from your machine
    From the Git Rewind project folder:
    node bin/git-rewind.mjs /path/to/repo --out history.json
  2. 02
    Open your history file
    Includes authors, file paths and patches. Review before sharing.
No account. No backend. No upload.
